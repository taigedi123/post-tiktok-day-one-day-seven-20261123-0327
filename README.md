A 23-second vertical video about "Star Hop", a tiny platformer my AI
agent built and then updated every day for a week. The video cuts
between the identical moment in the game a week apart: DAY 1 is the
bare first build — a plain white square, a few coins, no HUD — and
DAY 7 replays the same map and the same start with a sky, clouds,
hills, patrolling enemies, coin-pickup particles, a score HUD and a
power-up star, ending on a "WEEK COMPLETE!" finale. The camera never
moves, so the change is the whole story. It closes on the newer build
being played, an invitation to start yours at make.fun, and make.fun's
referral end card carrying the referral code 5xww654b.

`VIDEO.json` names the video as posted on TikTok; `main.ts` (Node 22)
copies it to the output directory for the grader.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
